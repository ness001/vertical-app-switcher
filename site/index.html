Ready when you are

Download. Set up.
Make your next move.

macOS 13 or newer

One universal package for Apple Silicon and Intel. No .NET runtime or developer tools needed.

Download for macOS ↓
  1. Extract the ZIP and move Vertical App Switcher.app to Applications.
  2. Open the app. Enable it in System Settings → Privacy & Security → Accessibility.
  3. Choose and save your shortcut in setup.

Packages are not notarized. Follow your organization’s security policy if macOS blocks opening the app.

Read the macOS guide ↗

Windows 10 / 11

The small, framework-dependent EXE uses the separately installed .NET Desktop Runtime. Choose the package that matches your PC.

Download x64 ↓Download Arm64 ↓

  1. Extract the ZIP and run VerticalAppSwitcher.exe. Keep LICENSE and NOTICE with it.
  2. If .NET is missing, select Download it now in the prompt to open Microsoft’s download page. Install the latest .NET 10 Desktop Runtime matching your package (x64 or Arm64), then run the EXE again. Choose Desktop Runtime, not just .NET Runtime.
  3. Choose a shortcut and select Save shortcut.

Windows 11 does not include this runtime by default. Windows packages are unsigned; follow your organization’s security policy if a warning appears. Running the switcher needs no administrator access; installing the runtime system-wide requires administrator approval.

Read the Windows guide ↗
